# ✈️ Airline Reservation System

A simple Airline Reservation System developed using **HTML** for the frontend, **PHP** for backend processing, and **C** for reservation management logic. The system allows users to book flights, view reservation details, and manage airline records through an easy-to-use interface.

---

## 📌 Project Overview

The Airline Reservation System is designed to simplify the process of airline ticket booking and reservation management. Users can enter passenger details, choose available flights, and generate reservation records. The backend processes booking requests while the C program handles core reservation operations efficiently.

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/ANUSHUYA1010/Airline-reversation-system.git
```

### 2. Open Project Folder

```bash
cd Airline-reversation-system
```

### 3. Start PHP Server

Place the project inside the **htdocs** folder (XAMPP) and start:

- Apache Server

Then open:

```
http://localhost/Airline-reversation-system/
```

### 4. Compile C Program

```bash
gcc airline.c -o airline
```

### 5. Run C Program

```bash
./airline
```

(Windows)

```bash
airline.exe
```
